AdPulse – Publisher Revenue & Bid Strategy Tracker

A performance dashboard for a (simulated) ad marketplace: publisher traffic, **Pub TAC** (traffic acquisition cost), revenue and margin, broken down by bidding strategy.

Built with **React 18 · TypeScript · Vite · Tailwind CSS 4 · Redux Toolkit + RTK Query · Chart.js · TanStack Table/Virtual**, with a serverless API on **Netlify Functions**.

> Demo project. All data is generated by the API, deterministic per query (same dates + filters → same numbers).
